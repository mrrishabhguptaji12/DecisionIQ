# DecisionIQ: AI-Powered Business Insights (Starter)
A demo business analytics app using synthetic sales data, KPI summaries, filters, and a simple what-if margin scenario.
This starter does not implement a production-grade natural-language-to-SQL system or verified LLM/RAG pipeline.

## Run
```bash
pip install -r ../requirements.txt
streamlit run app.py
```
